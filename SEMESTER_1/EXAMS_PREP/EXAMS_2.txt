------------------------------------------------------------
In Linux/Kali, libraries are stored in specific system directories (folders).

Common library locations:
Example:
/lib
/lib64
/usr/lib
/usr/lib64
/usr/local/lib

Python libraries:
Example:
/usr/lib/python3/
/usr/local/lib/python3.x/
/home/user/.local/lib/

What each location means
| Directory        | Purpose                                       |
| ---------------- | --------------------------------------------- |
| /lib           | Essential system libraries needed for booting |
| /lib64         | 64-bit system libraries                       |
| /usr/lib       | Most installed application libraries          |
| /usr/local/lib | Libraries installed manually from source      |
| /usr/share     | Shared program data (not binary libs)         |

Example library files
Example:
/usr/lib/libssl.so
/usr/lib/x86_64-linux-gnu/libcrypto.so
/lib/x86_64-linux-gnu/libc.so.6

Find a library
Example:
find /usr/lib -name "libssl"

Check where a command gets libraries
Example:
ldd /bin/ls

Shows linked libraries used by the program.

Search all library cache
Example:
ldconfig -p

Displays registered shared libraries.

Important Linux library extension
Example:
.so  → Shared Object library

Similar to:
Example:
.dll in Windows
.dylib in macOS
