Cybersecurity Concepts – Definitions:

1. Confidentiality
Definition:
Confidentiality ensures that information is accessible only to authorized users and cannot be viewed by unauthorized individuals.
How it is achieved:
- Encryption (AES, RSA)
- Access controls
- VPNs
Example:
An encrypted email can only be read by the intended recipient.

2. Integrity
Definition:
Integrity ensures that data remains accurate, complete, and unaltered during storage or transmission.
How it is achieved:
- Hashing (SHA-256)
- HMAC
- Digital signatures
Example:
If a file is modified, its hash value changes, indicating tampering.

3. Authentication
Definition:
Authentication is the process of verifying the identity of a user, device, or system.
Methods:
- Username and password
- Digital certificates
- Digital signatures
- Multi-factor authentication (MFA)
Example:
Logging into OpenVPN with a username and password.

4. Non-Repudiation
Definition:
Non-repudiation prevents a sender from denying that they sent a message or performed an action.
How it is achieved:
- Digital signatures
Example:
A signed electronic contract proves who signed it.

5. Encryption
Definition:
Encryption is the process of converting readable data (plaintext) into unreadable data (ciphertext) to protect confidentiality.
Example:
AES encrypts VPN traffic.

6. Decryption
Definition:
Decryption is the process of converting ciphertext back into readable plaintext using the correct key.

7. Symmetric Encryption
Definition:
A cryptographic method that uses the same secret key for both encryption and decryption.
Advantages:
- Fast
- Efficient
Disadvantages:
- Key distribution problem
Examples:
- AES
- DES
- 3DES

8. Asymmetric Encryption
Definition:
A cryptographic method that uses two mathematically related keys: a public key and a private key.
Public Key:
Can be shared openly.
Private Key:
Must remain secret.
Examples:
- RSA
- ECC

9. Public Key
Definition:
A key that can be shared publicly and is used for encryption or signature verification.

10. Private Key
Definition:
A secret key used for decryption or creating digital signatures.

11. Hash Function
Definition:
A mathematical function that converts data of any size into a fixed-length value called a hash or digest.
Properties:
- One-way function
- Fixed output size
- Sensitive to input changes
Example:
SHA-256

12. SHA-256
Definition:
A secure cryptographic hash algorithm that produces a 256-bit hash value and is commonly used to verify data integrity.

13. HMAC (Hash-based Message Authentication Code)
Definition:
A mechanism that combines a hash function and a shared secret key to provide integrity and authentication.
Example:
Used in OpenVPN and TLS.

14. Digital Signature
Definition:
A cryptographic mechanism created using a sender's private key to provide authentication, integrity, and non-repudiation.
Process:

1. Hash message.
2. Sign hash with private key.
3. Verify using public key.

15. Digital Certificate
Definition:
An electronic document that binds a public key to an identity and is issued by a trusted Certificate Authority (CA).
Purpose:
- Authentication
- Trust establishment

16. Certificate Authority (CA)
Definition:
A trusted organization that issues and verifies digital certificates.
Example:
Browsers trust certificates issued by recognized CAs.

17. Diffie-Hellman (DH)
Definition:
A key exchange algorithm that allows two parties to securely generate a shared secret over an insecure network without transmitting the secret itself.
Purpose:
- Key exchange
Does NOT provide:
- Encryption
- Authentication

18. Shared Secret
Definition:
A secret value independently generated by two communicating parties and used to derive encryption keys.

19. Session Key
Definition:
A temporary encryption key used for a single communication session.
Example:
AES key generated after a Diffie-Hellman exchange.

20. AES (Advanced Encryption Standard)
Definition:
A modern symmetric encryption algorithm used worldwide to protect data.
Key sizes:
- 128-bit
- 192-bit
- 256-bit
Used in:
- VPNs
- HTTPS
- Disk encryption

21. DES (Data Encryption Standard)
Definition:
An older symmetric encryption algorithm using a 56-bit key.
Status:
Obsolete and insecure.

22. 3DES (Triple DES)
Definition:
An improved version of DES that applies the DES algorithm three times.
Status:
More secure than DES but now deprecated.

23. TLS (Transport Layer Security)
Definition:
A protocol that provides secure communication over networks using certificates, key exchange, encryption, and integrity protection.
Used by:
- HTTPS
- OpenVPN
- Email security

24. OpenVPN
Definition:
A VPN solution that creates an encrypted tunnel between a client and server using TLS, certificates, Diffie-Hellman, AES, and HMAC.

25. VPN (Virtual Private Network)
Definition:
A technology that creates a secure, encrypted connection over a public network such as the Internet.

26. Ciphertext
Definition:
Encrypted data that cannot be understood without the correct decryption key.

27. Plaintext
Definition:
Readable, unencrypted data.

28. Key Exchange
Definition:
The process of securely establishing encryption keys between communicating parties.
Example:
Diffie-Hellman.

29. Game Theory
Definition:
A mathematical framework used to analyze strategic interactions between rational decision-makers.
In Cybersecurity:
Used to model attacker and defender behavior.

30. Strategy
Definition:
A plan or action chosen by a player in a game-theory scenario.

31. Payoff
Definition:
The reward or outcome a player receives after choosing a strategy.

32. Nash Equilibrium
Definition:
A situation where no player can improve their payoff by changing strategy alone while the other players keep their strategies unchanged.

33. Imperfect Information
Definition:
A situation where players do not have complete knowledge about the actions, intentions, or resources of other players.
Example:
Attackers do not know all defensive controls; defenders do not know all attacker plans.

34. Cybersecurity
Definition:
The practice of protecting systems, networks, applications, and data from unauthorized access, attacks, damage, or theft.

35. Digital Forensics
Definition:
The process of identifying, collecting, preserving, analyzing, and presenting digital evidence for investigative or legal purposes.

Ultimate Memory Sentence:
Confidentiality is provided by encryption, integrity by hashing and signatures, authentication by passwords, HMACs, certificates, and signatures, 
non-repudiation by digital signatures, key exchange by Diffie-Hellman, and fast data protection by AES within protocols such as TLS and OpenVPN.
