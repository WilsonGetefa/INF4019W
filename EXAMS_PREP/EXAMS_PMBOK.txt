1) Activity network (AON structure)
Dependencies:
* A → C

* C & D → G
* F → H, I
* E, G, H, I are end activities

AON diagram (text form):

2) All possible paths through the network
We list complete start-to-finish paths:
1. A → C → G
   Duration = 5 + 2 + 4 = 11

2. B → D → G (joins with C at G requirement)
   Duration = 4 + 1 + 4 = 9

3. B → F → H
   Duration = 4 + 5 + 3 = 12

4. B → F → I
   Duration = 4 + 5 + 2 = 11

5. B → E
   Duration = 4 + 5 = 9

3) Critical Path
The longest path determines project duration.
B → F → H = 12 (longest)

So:
✅Critical Path: B → F → H

⏱ Project Duration: 12 time units
4) Key insight
Even though A → C → G is fairly long (11), it is not critical because it finishes earlier than the B–F–H chain.
The bottleneck is clearly the branch through F and H.

Step 1
• Identify all tasks
• Determine task dependencies
• Draw and label each task (e.g. for each ID enter an appropriate identification number)
• Enter the task duration for each task

Step 2 – Enter the Earliest Start (moving from left to right)
1. Task A earliest start is Zero (0)
2. Task B earliest start = Earliest start (Task A) + Duration of Task A
3. Task E: If a successor task has more than one predecessor task, use the highest Earliest start of the predecessor tasks.
    Hence for Task E, Earliest start for B = 6, earliest start for C =
6, THEREFORE Earliest start for E will be 14

Step 3 – Determining Latest start time & the Critical Path (moving from right to left)
• Determine the Earliest finish time for the right-most task. In our case this will be Task F = 21 + DURATION = 21 + 7 = 28.
• Determine the Latest start for the right-most task by subtracting its duration from the Earliest Finish
• Task F latest start = 28 – 7 = 21
• Latest start for Task E = Latest start Task F – duration of Task E, 21 – 7 = 1
