Is it possible to find which software the user was using at that time?
Yes — absolutely. That is one of the main goals of memory forensics using tools like Volatility 3 and Volatility 2.
From a RAM image, you can often determine:
- which applications were running
- what documents were open
- browser activity
- chat sessions
- command history
- malware execution
- USB devices
- network connections
- decrypted data in memory
- clipboard contents
- passwords/tokens (sometimes)


1. Find Running Software
The first step is usually:
#Volatility 3

python3 vol.py -f AdamFTriage.mem windows.pslist
```

#Volatility 2

```bash id="u3i3dq"
python2 vol.py --profile=Win7SP1x64 -f AdamFTriage.mem pslist
```

This shows active processes such as:

| Process        | Meaning               |
| -------------- | --------------------- |
| chrome.exe     | Google Chrome open    |
| firefox.exe    | Firefox running       |
| outlook.exe    | Email client          |
| winword.exe    | Microsoft Word        |
| putty.exe      | SSH session           |
| cmd.exe        | Command prompt        |
| powershell.exe | PowerShell            |
| wireshark.exe  | Packet capture        |
| malware.exe    | Suspicious executable |

2. Find Hidden or Injected Malware

Very important forensic step:

```bash id="n67x44"
windows.malfind
```

or in Volatility 2:

```bash id="35s8t4"
malfind
```

This detects:

injected code
reflective DLL injection
shellcode
process hollowing

12. Very Important Reality

RAM only shows:

what existed during capture time

NOT:

entire historical usage

If the program:

was closed long ago
memory overwritten

then evidence may disappear.

But memory is extremely valuable because it preserves:

live state
decrypted information
volatile evidence
